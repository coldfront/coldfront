# Upgrading ColdFront

!!! warning "For versions v2.0.x and above"
    This document covers upgrading v2.0.x and above. For information on
    upgrading the older v1.1.x please [see here](https://docs.coldfront.dev/en/stable-1.1.x/).

This document describes how to upgrade ColdFront. New releases of ColdFront
can introduce breaking changes. Refer to this document before you upgrade.

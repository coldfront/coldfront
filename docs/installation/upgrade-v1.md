# Upgrading from ColdFront v1.1.x

This document describes how to upgrade ColdFront from an older 1.1.x release.
Version 2.0.x of ColdFront was a complete re-write of the codebase and is not
backward compatible. You can NOT migrate directly from v1.1.x to v2.0.x and must
dump your data and re-import.
